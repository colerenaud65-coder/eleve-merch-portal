# ELEVÉ — Private Reserve & Luxury Cannabis Menu

A dark-mode, high-converting private storefront and reserve menu built for **Elevé**, optimized for deployment on **Vercel**.

## Features
- **Passcode & Age Verification Gate**: 19+ / 21+ access lock (Passcode: `LEAF24` or `ELEVE24`).
- **Dynamic Category Filtering**: Headstash Flower, Indoor Flower, Rosin, Hash Holes, Apparel, and Seeds.
- **Tier & Variant Selectors**: Real-time weight selection (1 oz, ½ lb, 1 lb, 1g, 2g, apparel sizes) with live pricing recalculation.
- **Slide-Out Order Drawer**: Interactive cart with live subtotal calculation.
- **VIP Communication Rails**: Direct order routing via Signal (`muskokasmoke.01`), Telegram (`@Bay_Area_exotics`), and WhatsApp (`+1-249-358-1049`).
- **Supported Payment Rails**: Interac E-transfer, Crypto (-5% discount applied), PayPal Friends & Family, and Cash on delivery.
- **ELEVÉ OS Portal**: Built-in simulated back-office dashboard for operations and inventory tracking.

## Deploying to Vercel via GitHub
1. Upload or push these files to your GitHub repository.
2. Go to [Vercel](https://vercel.com/) and click **Add New…** › **Project**.
3. Import your GitHub repository.
4. Leave **Framework Preset** as **Other** (Root directory `./`, no build command needed).
5. Click **Deploy**. Vercel will launch your live site with global edge CDN and custom SSL instantly!
